# SumLab | JavaScript Addition Exercise

[![Live Demo](https://img.shields.io/badge/Live_Demo-Open_Project-2563EB?style=for-the-badge&logo=vercel&logoColor=white)](https://addition-console-exercise-2-mjs.vercel.app/)

A small JavaScript practice project that asks for two numbers, calculates their sum, and displays the values in the page and browser console.

## ✨ What it does

- Prompts the user for two values.
- Converts the entered values to numbers.
- Calculates the sum.
- Logs the entered values and result to the browser console.
- Displays the calculation in the page output area.

## 🛠️ Built with

- HTML5
- JavaScript

## ▶️ Run locally

~~~bash
git clone https://github.com/modewika1-star/t8-2.git
cd t8-2
~~~

Open `index.html` and click **Calculate**. Enter the requested values in the browser prompts.

## 📁 Files

- `index.html`: calculator heading, action button, and output area.
- `script.js`: prompt handling and addition logic.
